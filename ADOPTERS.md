# DocBrain Adopters

This file tracks organizations and teams that are using DocBrain in their engineering workflows. Adoption helps the project demonstrate maturity as it progresses through the CNCF lifecycle.

## How to be added
If you are using DocBrain, please submit a Pull Request to add your organization to this list. Please include:
- Organization Name
- A brief description of your use case (e.g., "Indexing On-call Runbooks")
- (Optional) A link to your website or a contact person
